Professional Summary

Samit Shahnawaz Miftah is a PhD researcher in Computer and Systems Engineering at Rensselaer Polytechnic Institute, specializing in hardware security, formal verification, and AI-driven design automation. With 10 peer-reviewed publications across top venues including IEEE MICRO, ACM/IEEE DAC, and IEEE TCAD, his work advances automated and intelligent methodologies for securing next-generation hardware systems. He is also a two-time top finisher at Hack@DAC — the world’s premier hardware security competition — and a CSAW AI Hardware Attack Challenge awardee.

Projects

  • Using LLM Agents for SystemVerilog Assertion Generation

    This project explores the application of Large Language Model agents for generating SystemVerilog assertions, aiming to improve the efficiency and effectiveness of hardware verification processes.

    • Created a synthetic dataset of synchronous and asynchronous assertions to train language models. [published in TODAES’25]
    • Fine-tuned open-source models (Llama 3.1 8B, DeepSeekCoder 6.7B) to generate assertions (for OpenTitan, CVA6, Pulpissimo). [published in VTS’25]
    • Using the fine-tuned LLMs to spawn agents that would go through the design files and the documentation to understand the design structure and generate SystemVerilog assertions accordingly on AI accelerator architectures (NVDLA).
    • Binding the generated assertion files to their corresponding design files.
    • Calling verification tools used to check the correctness of the assertions.
  • Automatic Program Repair

    This project focuses on developing techniques for automatic program repair, leveraging generative AI and formal methods to identify and fix bugs in software systems.

    • Once design faults are identified and localized using the fuzzing and localization tools, using LLM agents to repair the buggy designs.
    • The agents are given context by the respective bug description from which the assertions were generated.
    • A verification loop is implemented to verify the correctness of the design once the patch is applied.
